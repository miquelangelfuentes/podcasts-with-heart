# Privacy Policy

**Podcasts with Heart** is a standalone, free, and open-source educational desktop application designed for teachers, students, and podcast creators.

## 1. Personal Data Collection
The application **does not collect, store, transmit, or process any personal data** from its users.
- No user accounts or registrations are required.
- No cookies, device identifiers, analytics, or tracking tools are used.
- No telemetry or telemetry logs are collected or sent to external servers.

## 2. Text and Audio Processing
- With offline autonomous voice models (Piper Neural, Kokoro ONNX), all voice synthesis is performed 100% locally on the user's workstation. No audio or script content ever leaves the computer.
- When using optional cloud synthesis, only the specific text block needed for speech conversion is transmitted, with zero user identification or persistent data retention.

## 3. Contact & Open Source Transparency
For questions regarding data privacy or the source code, please visit or open an issue on the official GitHub repository:
https://github.com/miquelangelfuentes/podcasts-with-heart
